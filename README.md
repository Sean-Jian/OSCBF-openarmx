# OSCBF-openarmx

#### 介绍
使用开源硬件复现论文OSCBF，打通sim2real全流程 实现本体碰撞避免和双臂互碰避免，还能拓展到奇异点避免和通用避障场景
仿真部分：主目录py文件
实机部分：openarmx_teleop_bimanual/src/oscbf_mit_controller.cpp
